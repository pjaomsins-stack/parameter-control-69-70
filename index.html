ต้องจัดการก่อน

เรียงตามความรุนแรง: หลุดเป้าแล้ว, แนวโน้มจะหลุดใน 14 วัน, โอกาสหลุดเป้าใน 7 วัน (พารามิเตอร์ที่กระทบ loss มีน้ำหนักมากกว่า)

ให้ Claude วิเคราะห์

ส่งสรุปสถิติและผลพยากรณ์ของโรงงานนี้ให้ Claude หาสาเหตุที่เป็นไปได้ และลำดับสิ่งที่ควรทำ

ผลวิเคราะห์จะแสดงที่นี่ ใช้เวลาประมาณ 20–40 วินาที

ผลวิเคราะห์ที่บันทึกไว้

ทุกคนที่เปิดหน้านี้ดูผลวิเคราะห์ย้อนหลังของโรงงานนี้ได้ และดาวน์โหลดเป็นไฟล์ HTML ไปส่งต่อหรือพิมพ์ได้

ค่าสะสม (todate) ของแต่ละโรงงานเทียบกับเป้าของตัวเอง สีพื้นแสดงสถานะ ★ คือโรงงานที่มีระยะห่างจากเป้าดีที่สุด คลิกแถวเพื่อดูกราฟเทียบรายวัน

พารามิเตอร์ย้อนหลังหลายฤดู

เลือกฤดูที่ต้องการดู และฤดูที่จะเทียบ ค่าที่แสดงคือค่าสะสม (todate) ทั้งฤดู เทียบกับเป้าของฤดูนี้

Imbibition กับ % Pol extraction และความชื้นชานอ้อย

Scatter แยกชุดหีบ A, B, C และ S ฤดู 60/61 ถึง 68/69 จากหน้า Imbibition Scatter เดิมของทีม

เปิดเต็มหน้าจอ ↗

ข้อมูลที่กรอกหรืออัปโหลดในหน้านี้ยังไม่ถูกบันทึกลงฐานข้อมูล จะหายเมื่อรีเฟรช เหมือนการใช้งานหน้าเดิม

Summary Report เทียบหลายฤดูผลิต

ค่าสะสม (todate) ตามวันหีบ ฤดู 63/64 ถึง 68/69 อ่านจากเส้นกราฟในรายงาน Summary Report (Power BI) ของ Line AB, C และ S ตัวเลขท้ายเส้นคือค่า ณ วันสุดท้ายของฤดู

ค่าสิ้นฤดูของแต่ละพารามิเตอร์ และการเปลี่ยนแปลงของ 68/69 เทียบ 67/68

ให้ Claude วิเคราะห์หมวดนี้

ส่งค่าทุกฤดูของหมวดที่เลือกให้ Claude สรุปแนวโน้ม จุดที่ดีขึ้นหรือแย่ลง และสิ่งที่ควรเตรียมสำหรับฤดู 69/70

ผลวิเคราะห์จะแสดงที่นี่

% pol ในอ้อย ค่าสะสม (milling loss ของ AB ถ่วงน้ำหนักตามตันอ้อย/ชม. ของชุด A และ B)

ถ้าลด loss ได้ จะได้น้ำตาลเพิ่มเท่าไร

ปรับสมมติฐานให้ตรงกับโรงงาน แล้วเลื่อนแถบเพื่อจำลองการลด loss แต่ละส่วน

ตัวแปรที่เคลื่อนไหวไปพร้อมกับ loss

ค่าสหสัมพันธ์ (r) รายวันกับ loss ในกากน้ำตาล และ undetermined loss ของโรงงานนี้ ใช้ชี้จุดที่ควรตรวจก่อน ความสัมพันธ์ไม่ได้ยืนยันว่าเป็นสาเหตุ

หนึ่งแถวต่อหนึ่งวันต่อหนึ่งชุด คอลัมน์ day, unit (A, B, AB, C, S) แล้วตามด้วยรหัสพารามิเตอร์ในตารางด้านล่าง ส่งออกจาก Amazon QuickSight หรือ Excel แล้ววางได้เลย
